Configuração (uma vez)

  1. Windows: baixe instalar-windows.bat e pc_remote_server.py (pasta pc-remote do repositório) para a mesma pasta e dê dois cliques no .bat. Ele faz os passos 2 e 3 sozinho; depois reinicie o app.
  2. Ou, manualmente: instale o Python e rode pip install "mcp>=1.9" pynput.
  3. Salve pc_remote_server.py (pasta pc-remote do repositório) no PC.
  4. No app Claude para desktop, abra Configurações → Desenvolvedor → Editar configuração e adicione o servidor abaixo. Reinicie o app.
  5. Abra este controle no app desktop, toque em Ativar receptor e permita o acesso.
{
  "mcpServers": {
    "pc_remote": {
      "command": "python",
      "args": ["C:\\Users\\VOCE\\pc-remote\\pc_remote_server.py"]
    }
  }
}
